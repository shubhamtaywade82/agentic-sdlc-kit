# Prompt: Implement Next Task (TDD)

Open docs/plans/<slug>.md and take the next unchecked task.
1. State the task and the files you will touch.
2. Write the failing test. Run it and show the failure.
3. Implement the minimum code to pass. Run the test and show it passing.
4. Refactor if useful; keep tests green.
5. Run the full relevant suite + lint + type-check; show results.
6. Commit with a conventional message and tick the task in the plan.
7. Report using the AGENTS.md communication format, then stop.
If the spec looks wrong or the task grows > 2x, stop and ask me.
